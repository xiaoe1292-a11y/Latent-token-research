# 历史实验实现

本目录保存已完成实验的训练、推理、诊断和资源调度实现，供查看代码与核对历史哈希。没有复制上游 Latte 模型主体，模型与 tokenizer 仍来自固定官方 commit。

| 目录 | 内容 |
|---|---|
| `phase1/` | 五组训练/评估、指标与历史完成调度/报告适配 |
| `phase2/` | 固定实际 Beam 推理、路径诊断与全量候选审计 |
| `joint16/` | 16 组扩展、已有结果复用、关键重放、共享卡性能与报告 |
| `runtime_helpers/` | 训练、批构造、恢复和集群资源辅助代码 |

文件保留其历史运行路径，以便理解原环境和源码哈希；这些路径不是当前仓库的安装路径。调度器还依赖原批次状态、数据缓存、SID、Checkpoint 和运行时，**不要直接运行历史 manager/init 命令来测试公开包**。环境迁移范围见[复现说明](../docs/REPRODUCIBILITY.md)。

公开包的可直接执行入口是顶层 `scripts/`；它们只在 CPU 上使用已经发布的数值记录。连接服务器的 SSH/部署脚本没有放入本目录。

文件哈希见 [`reference-source-sha256.json`](../provenance/reference-source-sha256.json)。原始版本保留与当前可移植分析代码是不同用途；不把 CPU 数值复核称为重新执行 GPU 推理。
